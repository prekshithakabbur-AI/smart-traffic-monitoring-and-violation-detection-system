# smart-traffic-monitoring-and-violation-detection-system
An intelligent traffic monitoring system that uses AI and computer vision to detect vehicles, analyze traffic density, and identify traffic violations such as signal jumping, overspeeding, and wrong-side driving. The system aims to improve road safety and support smarter traffic management.

Vehicle Detection: Detects vehicles from traffic video footage using YOLOv8.
Traffic Density Analysis: Monitors vehicle counts and congestion levels.
Violation Detection: Identifies traffic violations such as signal jumping, overspeeding, and wrong-side driving.
Number Plate Recognition: Uses OCR to recognize vehicle registration numbers.
Evidence Capture: Captures images of detected violations.
Admin Dashboard: Displays traffic information and violation records.
Smart Traffic Management: Supports better traffic monitoring and road safety.
